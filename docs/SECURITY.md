# Segurança e escopo

O modo inicial é somente demonstração e não abre conexões de rede. Nunca use endereços ou dados de terceiros sem autorização. Não há credenciais nem comandos remotos. A limpeza atua somente na tabela local de eventos; auditoria é preservada. SNMP/SSH ainda não foram implementados, apesar das dependências disponíveis no Maven.
