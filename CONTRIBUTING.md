# Como contribuir

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch para a alteração.
3. Mantenha regras de negócio fora da interface e não adicione dados/credenciais reais.
4. Execute `mvn clean test` e descreva os resultados no pull request.
5. Para integrações, documente protocolo, permissões, limites e fontes dos dados.
